# خريطة نقل المحتوى وإعادة تصميمه

سيحافظ الموقع الجديد على رسالته الحالية القائمة على الأثر الزراعي، مع نقل البعد المؤسسي والتشغيلي الذي يوضحه الموقع السابق. سيعاد تقديم ذلك بصياغة موجزة وتحريرية، بحيث يقرأ الزائر هوية الجمعية ثم مجالات عملها ثم التزامات الحوكمة، بدلًا من تكرار صفحات وصفية طويلة.

| مادة الموقع السابق | موضعها في الموقع الجديد | المعالجة الجديدة |
|---|---|---|
| نبذة الجمعية ورسالتها | قسم «عن الجمعية» | تأكيد نموذج العمل التعاوني وتوليد القيمة الاقتصادية والاجتماعية والاستدامة. |
| الأهداف التفصيلية | قسم «مسارات التنمية» | ستة مسارات مرئية تشمل الإنتاج، البيوت المحمية، المشاريع الحيوانية، التدريب، الشراكات، والمدخلات والتسويق. |
| كلمة الرئيس | قسم «رؤيتنا للمستقبل» | بيان مؤسسي قصير يركّز على الأمن الغذائي والابتكار وكفاءة الموارد دون عرض بيانات شخصية. |
| الحوكمة والوثائق | قسم «الحوكمة والشفافية» | مبادئ مرئية وفئات للوثائق، مع طلب اعتماد نسخ الوثائق قبل نشر ملفاتها للتحميل. |
| الاستبيانات | امتداد مستقبلي للوحة الإدارة | لا تُنقل كنماذج عامة قبل مراجعة الأسئلة والخصوصية وسياق كل فئة. |

لا تُنقل تلقائيًا أرقام التواصل القديمة أو البريد السابق أو الحسابات البنكية أو بيانات الأفراد. يبقى بريد الموقع الجديد `info@acsd.sa` هو وسيلة التواصل الرسمية الحالية.
